Video Csound

Generating Music from Video with Object Tracking through Computer Vision

Source Code Thesis Paper

Overview

Traditional acoustic instruments offer a natural, symbiotic relationship between physical action and sonic response. In contrast, laptop-based electronic music often lacks this visual expressiveness, making it difficult for an audience to interpret the relationship between a performer's actions and the resulting sound.

VideoCsound is an open-source performance system designed to bridge this gap. Unlike previous interfaces that rely on physical markers (fiducials), VideoCsound utilizes state-of-the-art computer vision to track everyday objects and translate their high-level semantic data (ex. position, scale, and occlusion) into real-time synthesis parameters.

By treating the visual world as a "tangible interface," the project creates a transparent, multimodal experience where the artistry hidden within data becomes both audible and visually intuitive to an audience.

Technical Implementation

VideoCsound is built on a modular Python pipeline that applies high-speed object detection with real-time audio synthesis. The project uses OpenCV for video processing and Ultralytics for computer vision model processing, together extracting bounding box coordinates and unique track IDs of objects found in the incoming video stream. The Csound Python API acts as the sound engine which drives the sound synthesis, modulating parameters of the sound by the bounding box data. OpenCV is used for the output video as well, overlaying visual indicators such as bounding boxes and track IDs onto the video feed to provide real-time feedback to the performer.

To facilitate rapid creative iteration, VideoCsound utilizes a template-based project structure that automates the environment setup for each performance. When initializing a new project, the system generates a standardized directory containing YAML configuration files and a boilerplate Csound orchestra (.orc) file. This approach decouples the core computer vision engine from the creative sound design assets, allowing users to define complex object-to-audio mappings in a centralized folder, avoiding altering the underlying Python source code. By centralizing parameters like detection thresholds, Csound bus names, and MIDI mappings within these templates, the system ensures that all user editted files are bundled into a single folder, allowing easy experimentation and sharing of projects.

Key Outcomes

The VideoCsound project demonstrates the potential for using semantic data from video to drive audio synthesis in a real-time performative context. The research resulted in several key findings for the field of interactive musical systems:

  • Marker-less Tangible Interface: Proved that modern object detection (YOLO11) can replace traditional fiducial markers, allowing everyday environments and household items to serve as intuitive musical controllers, greatly reducing setup complexity and increasing accessibility.
  • Performative Occlusion: Discovered that the physical act of hiding and revealing objects creates a natural "performative affordance," providing an easy and intuitive method for starting, stopping, and structuring sounds during a live performance.
  • Semantic Mapping: Successfully implemented a pipeline that maps 3D bounding box parameters (position, width, and height) to synthesis variables, creating a transparent link between visual motion and sonic response.
  • Open-Source Framework: Contributed a modular, template-based Python toolkit that allows other artists and researchers to experiment with data-driven sonification and marker-less audiovisual interaction.

Challenges and Solutions

Real-Time Audio Latency

A primary challenge identified across demonstrations was a consistent delay of approximately 500ms between visual events and their corresponding audio responses. This lag significantly detracted from the sense of direct, real-time interactivity required for a responsive musical instrument.

Solution: While the live processing approach was maintained for this prototype to prioritize real-time sound design experimentation, future optimizations focus on shifting video handling to native Ultralytics methods. This enables advanced techniques such as "video stride" (processing every Nth frame) and batch processing to significantly reduce the computational load on the processing pipeline.

Sonic Monotony with Static Objects

Initial tests revealed that stationary objects in dense scenes produced monotonous, undifferentiated drones because the audio was mapped strictly to shifting positional coordinates. This revealed the need for instruments that could create auditory interest independent of physical object movement.

Solution: Csound instruments were redesigned to include internal modulation, such as sample-and-hold based amplitude modulation. This allows the system to generate rhythmic and timbral interest over time, independent of changes in an object’s physical coordinates, ensuring a dynamic soundscape regardless of object movement.

Future Work

While VideoCsound serves as a successful prototype, the research identified three primary areas for expansion to evolve the system from an experimental tool into a versatile framework for data-driven art.

GUI Development

The current prototype relies on a command-line interface, which can be intimidating for non-technical users. Transitioning to a desktop application using a Python GUI toolkit like Tkinter or PySide would make the system more intuitive and accessible to artists and musicians without programming expertise.

Enhanced Parameter Mapping

Future development will focus on extracting more nuanced data beyond simple bounding box coordinates. This includes integrating object velocity and acceleration to map physical energy to sonic intensity, as well as using the model's confidence score to introduce organic instability or timbral variations based on detection certainty.

Expansion of Applications

The VideoCsound framework has potential applications beyond experimental music, including educational tools for demonstrating AI principles and practical scenarios like kinesthetic feedback for physical therapy or spatial audio alerts for industrial safety systems.
