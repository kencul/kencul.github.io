## Overview

Risk of Rain 2 (RoR2) is a fast-paced roguelike where movement is the primary survival mechanic. However, the game engine natively enforces a strict **1-to-1 keybinding constraint**, preventing players from assigning secondary keys to critical actions like sprinting.

<span className="text-highlight-light">Sprint Double Bind</span> is a BepInEx plugin that bypasses these engine limitations. By hooking into the game's runtime assembly, it enables complex input schemes—such as mouse-scroll sprinting—to improve accessibility and enable advanced mechanical techniques like the "Acrid Sprint Cancel."

## Core Functionality

The mod focuses on three primary input vectors that are otherwise unsupported or restricted within the vanilla configuration menu.

## Technical Implementation

The project utilizes **BepInEx** for assembly patching and **MonoMod** (via `On.RoR2`) to hook into the game’s internal classes. 

A significant challenge was the disparity between Unity's `Update()` (input polling) and the game's `FixedUpdate()` (physics/state processing). To prevent dropped inputs, the mod implements a **state-latching pattern**: 

1. **Update()**: Continuously polls `Input.mouseScrollDelta` and `UnityInput`.
2. **Flagging**: If a valid input is detected, a `_keyPressedThisFrame` flag is raised.
3. **FixedUpdate()**: The hook intercepts `PlayerCharacterMasterController`, checks the flag, and manually sets `sprintInputPressReceived = true` before the game processes the frame.
